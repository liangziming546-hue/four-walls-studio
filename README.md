# 四面之间 · 画室生存记

第一人称3D浏览器生存经营试玩版。房间包含工作区、补给交付区、休息区和图形俱乐部。

## 在线试玩与发布

游戏网址：[四面之间 · 画室生存记](https://liangziming546-hue.github.io/four-walls-studio/)。支持电脑键鼠与手机竖屏触控。

`main`分支更新后，GitHub Actions会自动安装组件、执行规则检查、构建并发布到GitHub Pages。发布配置位于 `.github/workflows/deploy-pages.yml`；仓库的 Settings → Pages → Source 应为 GitHub Actions。

线上构建使用仓库名称作为资源路径前缀，本地开发仍从根地址打开。部署状态可在仓库的 Actions 页面查看。线上存档保存在访问者自己的浏览器中，与本地试玩存档独立。

## 启动

安装 Node.js 20.19+ 或 22.12+，在本目录运行：

```sh
npm install
npm run dev
```

打开终端显示的本地地址。首次安装后可双击 `启动游戏.cmd`。支持 Chrome、Edge 等具有 WebGL 的桌面浏览器。

在Windows资源管理器的项目文件夹中双击启动文件，保持启动窗口开启，再等待浏览器自动打开游戏。启动失败时窗口会保留错误信息。启动文件直接调用本机Node.js与项目内的Vite，支持中文目录；批处理文件使用Windows CRLF换行，避免命令被错误拆分。

## 操作

- 手机自动显示底部单手操作区：长按前后左右按钮移动，长按转向、抬头或低头按钮调整视角，也可滑动画面。靠近并面向物品后点击“互动”或轻点画面。松手、手势取消、暂停或切换页面都会停止移动。无需连接键盘或锁定鼠标。
- 手机底部快捷栏可查看任务、打开背包、保存、暂停和查看说明；暂停窗口可切换左手或右手布局，偏好保存在当前浏览器。查看任务时暂停计时，操作窗口底部有返回按钮。画板支持手指描画与长按自动绘画，商店及老虎机按窄屏重排，长窗口可上下滚动。
- 手机采用适合竖屏的视角与较低的渲染分辨率，留出屏幕安全区域。电脑仍使用原有键鼠控制、画质和布局，不显示触屏按钮。
- WASD移动，鼠标观察，E互动，B背包，H说明，Esc暂停。右上角“保存”或Ctrl+S可立即保存进度，成功后显示提示；自动存档仍保留。
- 各交互窗口的内容居中，右上角“？”打开独立说明窗口；窗口标题与常驻玩法解释已移除，H也可打开说明。阅读说明时游戏暂停，关闭后返回原窗口。
- 在画桌选择图形，按住左键沿虚线手动画图。覆盖至少90%且线条偏差合格时立即自动验收并入库，没有最短作画时间，也不需要点击确认。
- 长按“自动画图”沿轮廓自动绘制，基础约20秒完成，升级与人物状态会影响用时。松开暂停，再次按住继续；一直按住可以连续作画。切换手动与自动会重新描画，未完成的笔迹不保存。
- 商店交付优先补旧欠，当日交足自动领薪。补给购买后在背包使用。存款每天结算10%利息。
- 老虎机可选择1/5/10倍，分别投入1/5/10块同类图形，所有奖励按相同倍率结算。挂件自动装备。
- 四列滚筒从左到右依次停稳。已开启横排任意位置的连续三联得5块、四联得15块，例如第2至4格三联同样中奖。没有三/四联时，任意位置同投注图形的连续二联返还整笔投入，多条二联只返还一次。不相邻的相同图形不计连线，高亮对应实际中奖或返还位置。
- 基础中间行三/四联中奖率9%；每次真正未中增加1.5个百分点，上限增加15个百分点，三/四联中奖后清零。二联返还不增减连败，连败加成可跨日保留。
- 任意横排四联炸弹，优先取消该次全部奖励并停机至次日。炸弹仅为机台符号，不能投注、领取或绘画；倍率和连败保护不会提高炸弹停机风险。
- 中奖或返还的图形块落入出币口，需点击领取才计入库存。未领取时不能再次投入，可离开或刷新后回来领取，跨日也不会清空。转动时可按Esc暂停。
- 上床结束一天，02:00强制睡眠；连续3个日结仍有欠额时游戏结束。

进度保存在当前浏览器的本地存储中；更换浏览器、地址或清除站点数据后无法继承。暂停和切换页面时停止计时。不保存未完成笔迹或玩家位置。已投入的抽奖结果、待领出币、连败加成和停机日期均会保存，转动期间刷新可继续原有结果，不会重新扣除投入。旧版存档会自动补齐机台状态，保留原有进度。

## 验证与构建

```sh
npm test
npm run test:browser
npm run build
npm run preview
```

`dist/` 是构建后的静态游戏。通过HTTP服务打开，不能直接双击其中的HTML文件。规则测试覆盖绘画判定、经济收支、跨日欠额、30天交付、利息、存档及老虎机结算。浏览器检查在Windows上使用已安装的Edge；其他系统需先执行 `npx playwright install chromium`。

核心数值位于 `src/game.ts`。绘画轮廓及判定位于 `src/drawing.ts`，场景位于 `src/room.ts`，界面与游戏循环位于 `src/main.ts`。房间使用程序生成的几何模型，书桌信件为后续扩展入口。

规则测试覆盖经济、绘画、跨日结算、老虎机二联返还、概率与连败封顶、炸弹优先级、倍投和旧存档升级；浏览器检查覆盖四列依次停转、暂停恢复、挂件高亮、点击领取、未完成抽奖恢复、未领奖励保存和睡到次日恢复机台。
